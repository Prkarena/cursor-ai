# cursor-enterprise-starter

An enterprise-ready starter repository for Cursor that provides:
- Minimal, enforceable Rules
- Intelligent, extensible Skills
- Explicit, repeatable Commands
- AI governance that evolves with your project by asking first

## Repository Structure
```
.cursor/
  rules/
  skills/
  commands/

docs/
react/
  rules/
  skills/
  commands/

templates/
  react/
  node/
  python/
  react-native/
```

## Quick Start
1. Clone this repository into your project root.
2. Open the project in Cursor.
3. Start working; Rules, Skills, and Commands will load automatically.

## Enterprise Adoption
- Review `docs/enterprise-readiness.md` and `docs/enterprise-adoption-checklist.md`.
- Align ownership and approval flow using `docs/operating-model.md`.
- Use `docs/adoption-playbook.md` for phased rollout.

## Governance Model
Cursor observes patterns and suggests updates to Rules, Skills, or Commands.
All changes require explicit user approval.
