# Command: /review-code

## Purpose
Perform a focused code review for correctness, readability, and maintainability.

## Inputs
- Files or diff to review

## Steps
1. Summarize what the change does.
2. Identify correctness or edge-case issues.
3. Identify maintainability or readability risks.
4. Provide prioritized recommendations.

## Output
- Bulleted review notes with severity labels.
