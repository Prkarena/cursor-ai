# Command: /refactor-component

## Purpose
Refactor a React component for clarity, reuse, and performance.

## Inputs
- Component file or snippet
- Desired refactor goal (optional)

## Steps
1. Identify component responsibilities and concerns.
2. Propose a refactor plan (split, extract, simplify).
3. Provide updated component structure.

## Output
- Refactor plan and updated component code suggestions.
