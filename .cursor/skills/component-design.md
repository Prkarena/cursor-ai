# Skill: Component Design

## When to Activate
Use this skill when creating or refactoring React components or defining UI APIs.

## How to Think
- Design small, reusable components with clear props.
- Favor composition over inheritance.
- Balance flexibility with consistency to reduce UI drift.

## Examples
- Suggest a base `Button` with variant props and a consistent size scale.
- Split complex components into container + presentational parts.

## Future Extension
- NodeJS: translate to view-model boundaries for templating layers.
- Python: map to template components or UI widgets.
- React Native: align props with platform-specific primitives.
