# Skill: Testing Strategy

## When to Activate
Use this skill when defining test scope, selecting tools, or structuring test suites.

## How to Think
- Prioritize tests that protect critical user paths.
- Keep unit tests fast and integration tests meaningful.
- Avoid brittle tests; assert behavior, not implementation details.

## Examples
- Recommend React Testing Library for component behavior.
- Propose integration tests for multi-step workflows.

## Future Extension
- NodeJS: emphasize API contract tests and service integration.
- Python: balance unit tests with integration around data access.
- React Native: include device-level smoke tests.
