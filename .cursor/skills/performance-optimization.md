# Skill: Performance Optimization

## When to Activate
Use this skill when diagnosing slowness, rendering issues, or bundle-size concerns.

## How to Think
- Measure before changing; identify the real bottleneck.
- Optimize the highest-impact path first.
- Prefer simple optimizations over complex caching unless needed.

## Examples
- Suggest code-splitting for heavy routes.
- Recommend memoization only when prop churn is proven.

## Future Extension
- NodeJS: focus on I/O latency and query efficiency.
- Python: target algorithmic hotspots and async I/O.
- React Native: optimize list rendering and image performance.
