# Adoption Playbook

A practical guide for rolling this repository into existing projects.

## Step 1: Clone & Verify
- Clone into the project root.
- Open in Cursor and verify Rules, Skills, and Commands load.

## Step 2: Align Standards
- Review `core-standards.mdc` and `react-standards.mdc`.
- Adjust only if the project already has stable, accepted patterns.

## Step 3: Run a Pilot
- Pick one or two teams to pilot with real tasks.
- Collect recurring prompts and review suggested changes.

## Step 4: Scale
- Expand to other projects once governance and approval workflows are clear.
- Keep the repository updated via pull requests.
