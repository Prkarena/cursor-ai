# How to Use with Cursor

1. Clone this repository into your project root.
2. Open the project in Cursor.
3. Cursor will load Rules, Skills, and Commands automatically.

## Everyday Workflow
- Use Rules as guardrails; they are always-on.
- Use Skills for deeper reasoning and guidance.
- Use Commands for repeatable actions like /review-code or /generate-tests.

## Approving Changes
When Cursor suggests a change, respond with explicit approval or denial.
Example responses:
- "Yes, add a rule for naming conventions in .cursor/rules/core-standards.mdc"
- "No, keep the current state management approach"
