# FAQ

## How does Cursor evolve configuration safely?
Cursor asks for explicit approval before changing any Rule, Skill, or Command.

## Where should reasoning live?
Reasoning belongs in Skills; Rules should be short and enforceable.

## Can we add stack-specific guidance?
Yes. Add stack-specific Rules and Skills under a new folder (e.g., `node/`).

## How do we handle conflicting standards?
Prefer project-specific Rules only when a stable pattern has emerged.
