# Enterprise Adoption Checklist

## Technical
- Cursor loads Rules, Skills, and Commands on open.
- Repo is cloned into project root and version-controlled.
- React standards align with the project’s stack version.

## Process
- Ownership and approvals are documented.
- Governance prompts are understood by the team.
- Change management path is clear (PRs, reviews, merges).

## People
- Onboarding materials are shared.
- Teams understand consent-first behavior.
