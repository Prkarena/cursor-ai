# Cursor-Optimized AI Context

This repository is optimized to give Cursor consistent, enterprise-grade context.

## Context Design
- Rules are short and enforceable.
- Skills contain reasoning, trade-offs, and examples.
- Commands provide deterministic actions.

## Why It Works
- Minimizes ambiguity during code generation.
- Encourages consistent, explainable decisions.
- Prevents silent configuration changes.
