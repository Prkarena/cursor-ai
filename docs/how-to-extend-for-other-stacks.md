# How to Extend for Other Stacks

This repository is designed to grow with your stack.

## Recommended Steps
1. Add stack-specific Rules under a new folder (e.g., `node/rules/`).
2. Extend Skills to include stack-specific guidance.
3. Add Commands for repeatable stack workflows.

## Examples
- NodeJS: add a Rule for API error handling and a Skill for service design.
- Python: add a Rule for typing discipline and a Skill for data access patterns.
- React Native: add a Rule for platform constraints and a Skill for UI performance.
