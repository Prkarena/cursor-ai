# Security & Risk Guidance

This repository focuses on preventive guardrails rather than implementation details.

## Guardrails
- Avoid insecure defaults and unsafe evaluation.
- Validate external inputs at boundaries.
- Require explicit approval for any data collection or tracking.

## Risk Management
- Use Rules to prevent high-risk behaviors.
- Use Skills to guide reasoning about trade-offs.
- Use Commands for repeatable security reviews when needed.
