# Philosophy

This repository is a living system for enterprise-grade AI behavior in Cursor.

## Minimal Rules, Strong Skills
- Rules enforce safety, constraints, and boundaries.
- Skills contain reasoning, context awareness, and adaptive guidance.
- Commands are explicit and repeatable actions.

## Why This Matters
- Reduces drift and inconsistency across teams.
- Encourages clear architecture without enforcing unnecessary complexity.
- Helps Cursor behave like a senior engineer over time.
