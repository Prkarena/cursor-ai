# Project Readiness Assessment

Use this assessment to determine if a project is ready to adopt this repository.

## Architecture Stability
- The project has a clear module or feature boundary strategy.
- Teams agree on naming and folder conventions.

## Workflow Stability
- At least one repeatable workflow exists (review, testing, release).
- There is a known owner for approving configuration changes.

## Adoption Fit
- The team is willing to use consent-first governance.
- Cursor is part of daily development workflows.
