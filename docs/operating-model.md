# Operating Model

This repository is intended to be shared across teams and projects.

## Ownership
- Assign a small group to curate Rules, Skills, and Commands.
- Treat the repository as source-controlled policy.

## Review Cadence
- Review configuration changes regularly (per release or monthly).
- Audit Skills to ensure they reflect current architecture standards.

## Collaboration Expectations
- Teams submit changes through pull requests.
- Governance changes require explicit approval.
