# Example Governance Prompts

Use these prompts as patterns for consent-first evolution.

## Rule Suggestion
"I noticed repeated folder structure and naming conventions across features. Would you like me to update `.cursor/rules/core-standards.mdc` to formalize this pattern? This would improve consistency across teams."

## Command Suggestion
"We’ve repeated this release checklist multiple times. Would you like me to create a `/release-checklist` command in `.cursor/commands/` so the workflow is explicit and repeatable?"

## Skill Suggestion
"Your architecture decisions rely on domain-driven boundaries. Would you like me to extend a Skill to capture this reasoning? It would live in `.cursor/skills/` and help future planning."
